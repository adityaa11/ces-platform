# AUI-007: Project Facts and Changes Done

- **State:** planned
- **Review batch:** BATCH-06
- **Depends on:** AUI-003, AUI-004
- **Baseline:** UI/UX Prototype PRD 5.2, 5.4, 6, 9.1, 9.3

## Outcome

Present non-workflow knowledge and incremental PRD evolution as source-grounded, navigable product surfaces.

## Scope

- Implement Project Facts groups, expandable detail, source history, and PRD-lens behavior.
- Implement Changes Done grouped by PRD increment.
- Represent established, clarified, expanded, superseded, and unresolved changes.
- Link representative changes to their affected workflow, fact, CES item, or project-level destination.

## Acceptance criteria

- Facts such as scope, responsibilities, constraints, protection, outputs, and commitments are first-class and traceable.
- Changes can be understood as an accumulated history rather than a raw document list.
- PRD lens behavior remains coherent in both surfaces.
- A user can inspect supporting source evidence from representative facts and changes.

## Validation

- Exercise change-kind and PRD-selection scenarios.
- Check expanded fact and change details at desktop and mobile widths.
