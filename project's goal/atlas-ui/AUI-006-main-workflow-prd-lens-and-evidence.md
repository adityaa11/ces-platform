# AUI-006: Main Workflow, PRD lens, and evidence

- **State:** planned
- **Review batch:** BATCH-05
- **Depends on:** AUI-003, AUI-004
- **Baseline:** UI/UX Prototype PRD 5.1, 6, 9.1, 9.3

## Outcome

Make accumulated PRD understanding easy to navigate and verify through a compact workflow overview, focused workflow pages, a global PRD lens, and evidence.

## Scope

- Implement the Main Workflow journey overview and focused semantic workflow pages.
- Implement PRD selection, highlighting, and isolation while retaining necessary structural context.
- Implement workflow-node evidence that reveals interpretation, exact quote, source document, and page.
- Implement reusable workflow, PRD-chip, source-history, and evidence components.

## Acceptance criteria

- Users can enter a focused workflow page without facing one overwhelming graph.
- A selected PRD's contribution is visibly distinguishable from accumulated context.
- The user can inspect source evidence for representative workflow nodes.
- Workflow page role, business question, expected result, source history, and node sequence are clear.

## Validation

- Exercise all-PRD, selected-PRD, and isolated-PRD fixture scenarios.
- Check evidence interaction at desktop and mobile widths.
