# CES-GF-AGB-015 - Knowledge-Agent Provider Conformance

**Status:** Proposed; implementation unauthorized
**Review class:** BATCHABLE
**Depends on:** Accepted AGB-014 and an additional approved provider/runtime

## Outcome

Demonstrate that the same registered Policy knowledge-agent contracts and
golden evaluations can qualify more than one provider/runtime without changing
CES semantic authority.

## Scope

- Server-controlled provider/model configuration behind existing aliases.
- The AGB-007 golden replay and representative rejection fixtures.
- Structural, provenance, semantic, governance, and project-independence
  evaluation with redacted operational evidence.

## Acceptance contract

- Providers receive identical governed contract obligations and cannot select
  their own prompts, schemas, tools, or authority.
- Evaluation measures invariant satisfaction, not imitation of Codex wording.
- Provider failures and semantic variance remain explicit and cannot alter
  accepted knowledge.
- No provider is promoted solely because transport-level execution succeeds.

## Explicit non-goals

- Automatic failover, provider ranking as semantic authority, mandatory
  multi-provider production, or blocking the first Safara replay on a provider
  that has not been separately approved.

## Review focus

Provider neutrality, evaluation comparability, redacted evidence, controlled
configuration, and unchanged semantic/governance contracts.
